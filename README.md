## About

I'm a cybersecurity student and bug bounty hunter. I look for vulnerabilities in web applications on HackerOne, Bugcrowd and Intigriti, and I write up what I find as clear reports with a proof of concept.

Outside of hunting, I study programming languages and tinker with electronics on Arduino.

## Current focus

| Hunting | Learning |
| :-- | :-- |
| **Web application security**<br>Finding and reporting vulnerabilities in real-world applications through bug bounty programs. | **Reverse engineering**<br>The basics: reading compiled code to understand what a program really does. |
| **Reports and PoCs**<br>Clear write-ups with a proof of concept that is easy to reproduce. | **Embedded electronics**<br>Hands-on projects with Arduino Uno. |
